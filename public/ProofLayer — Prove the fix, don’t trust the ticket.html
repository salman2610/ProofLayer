Four honest answers, not one green tick.

A 403 on one route doesn’t mean the weakness is gone. ProofLayer tests the security property, then reports what it actually found.

Fixed

Every test for the property passes, including bypass attempts.

Incomplete

The original attack fails, but another path still exposes the data.

Still vulnerable

The original issue reproduces. The ticket should reopen.

Inconclusive

The test couldn’t decide, so it never pretends to.

From finding to proof in five steps.

Import the report once. Every retest builds on the evidence from the original finding.

Find

A tester discovers that one user can open another user’s invoice.

Record

The finding, reproduction steps, request, response and expected behavior are stored.

Fix

Developers patch the app so people see only the invoices they’re allowed to see.

Retest

Authorized tests repeat the attack and try alternate paths to the same data.

Sign

The verdict, results and evidence hashes are sealed with an Ed25519 signature.
